# Supplementary electricity externality data

These workbooks support a separate marginal-emissions and externality analysis. They **do not** supply the current poster's central attributional U.S. grid factor, which is calculated in [`AGU_Token/numerical/`](../AGU_Token/numerical/README.md).

| File | Provenance and role |
|---|---|
| [`Long_Marginal.xlsx`](Long_Marginal.xlsx) | NREL 2023 Cambium long-run marginal emission-rate workbook, released February 2024. See [NREL Cambium](https://www.nrel.gov/analysis/cambium.html) and the workbook's “Description and Guidance” sheet. |
| [`Short_Marginal.xlsx`](Short_Marginal.xlsx) | EPA AVERT v4.3 avoided-emission rates for 2017–2023, released April 2024. See [EPA download page](https://www.epa.gov/avert/avoided-emission-rates-generated-avert) and the workbook's “README” sheet. |
| [`section_2_5_externality_trace_V2.xlsx`](section_2_5_externality_trace_V2.xlsx) | Project calculation workbook for a separate externality sensitivity. Its “Sources” and “Missing_Data_Audit” tabs document inputs and gaps. |

Short-run avoided rates, long-run marginal rates, and annual attributional electricity factors answer different questions. Do not substitute one for another without changing the study boundary and interpretation.
